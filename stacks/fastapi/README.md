# レーンD — Python / FastAPI 実装

動物病院の窓口業務システムを Python / FastAPI で実装したもの。
**学習・研究目的**の実装であり、複製・再配布・改変・商用利用は許可しない。

契約は `spec/` にある。**外から見た振る舞いはそちらが正**で、ここは実装の都合だけを書く。

## 動かす

```
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python run.py          # http://127.0.0.1:8004
```

ポート **8004** はレーンDの仮決め（5実装が同時に立つため）。`PORT` で変えられる。

## テスト

```
.venv\Scripts\python -m pytest        # レーンD自身のテスト（手元で確かめる用）
```

**これが緑でも「終わった」ことにはならない。** 完了の判定はリポジトリ直下の
共通テスト（`tests/`）が緑になったときだけ（`coordination/DECISIONS.md` 5節）。

## 構成

| 場所 | 中身 |
| --- | --- |
| `app/config.py` | 設定と **JST**。時刻はすべてここの `JST` で扱う |
| `app/db.py` | SQLite + SQLAlchemy 2.0 の土台 |
| `app/main.py` | アプリの組み立て。**統合点なのでレーン本体が持つ** |
| `app/routers/` | 領域ごとのHTTP経路 |
| `app/templates/` | Jinja2。`base.html` が全画面の骨 |
| `tests/` | レーンD自身のテスト |

## この実装で踏んだもの（記録）

| 事象 | 中身 |
| --- | --- |
| **Windows に OS のタイムゾーンDBが無い** | `ZoneInfo("Asia/Tokyo")` が `ZoneInfoNotFoundError` で落ちた（2026-09-05 実測）。`tzdata` を依存に入れて解決。契約が「日付・時刻は JST」なので、入れ忘れると**集計だけが後から死ぬ** |
| **SQLite は既定で外部キーを見ない** | 接続ごとに `PRAGMA foreign_keys=ON` を打っている。切れていると壊れた参照が**エラー無しで**保存できる |
| **starlette 1.6 の TestClient は `httpx` を非推奨にした** | `httpx2` に切り替えた |

## 型でどこまで弾くか（Pydantic の線引き）

この実装の見どころのひとつ。**「型で弾けること」と「業務として正しいこと」は別**である。

| 層 | 何をやるか | 例 |
| --- | --- | --- |
| **Pydantic（型）** | 形が壊れているものを弾く。**その場で単独で判定できるものだけ** | 日付が日付になっていない／数量が負／必須項目が無い |
| **業務の検証** | **他のデータを見ないと判定できないもの**を弾く | その飼主が実在するか／診察済みの伝票を書き換えようとしていないか／単価が未設定の明細 |

線引きの基準は **「DBを引かずに判定できるか」**。引かずに済むなら Pydantic、
引くなら業務の検証に置く。混ぜると、型の層がDBに触り始めてテストが重くなる。

**特に注意するもの**: 「単価が未設定の明細」は**型では弾かない**。
弾いてしまうと保存すらできなくなるが、契約は
**「合計は出し、未算入の行数を併記する」**ことを求めている（`spec/README.md`）。
未入力を 0 として集計するのも禁止されている。つまりこれは**型の問題ではなく表示の問題**である。
