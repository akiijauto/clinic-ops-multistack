## レーンへ：本格的な実装に入ってよい

土台（雛形・依存・テストの走る形・`/healthz`）ができているなら、画面の実装へ進んでください。

**進め方**

1. `spec/README.md` → `model.md` → `screens.md` → `acceptance.md` → `openapi.yaml` の順に読む
2. **`coordination/qa/rulings.md` を読む。** 指揮役が決めた事項があり、蒸し返さない
3. 領域ごとにサブエージェントを走らせる（`briefs/lane-*.md` の表）。
   **統合点（共通のモデル・レイアウト）は自分で書く**
4. `python tests/run.py http://localhost:<ポート>` を緑にする

**目印を2種類とも置いてください。**

- `data-testid` — その要素があるか（`openapi.yaml` の `x-data-testids`）
- `data-check` — その値が正しいか（`acceptance.md` のキー一覧）

片方だけでは判定できません。**画面が出ているのに数字が間違っている**状態が通ってしまいます。

## 契約に欠陥を見つけたら

- **実装が止まる** → 指揮役へ直接メッセージ
- **止まらない** → `coordination/qa/lane-*.md` に書いて、仮決めして**先へ進む**。
  仮決めしたことを必ず書き残すこと

**契約を自分で書き換えないこと。** 変更は全レーンに影響するので指揮役が判断します。
