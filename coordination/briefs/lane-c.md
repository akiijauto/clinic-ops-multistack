## あなたの仕事

動物病院の窓口業務システム **全26画面**を PHP / Laravel で実装し、
**共通テスト（`tests/`）を緑にする**。

PHP 8.4.24 + Composer 2.10.3。**Laravelの流儀に従う**。画面は Blade。

PHPの落とし穴を踏みやすい。**既定引数は引数を省略したときしか効かない**、`json_encode(5.0)` は `5` に正規化される、文字数は `mb_strlen` で数える（2026-09-05 に別プロジェクトで実測した3件）。

## 一人で26画面を抱えないこと

**あなた自身がサブエージェントを並列に走らせてください。** 領域は5つに分かれています。

| 領域 | 画面 |
| --- | --- |
| 1 受付・患者 | 一覧 / 新規 / 顧客 / 検索 / 来院履歴 / 削除 / 折りたたみ表示 / トップ |
| 2 診療 | カルテ / 検査 / 投薬 / 予防 / 書類 |
| 3 会計・売上 | 会計 / 会計履歴 / DM / **売上集計（新）** |
| 4 入院・予約・業務 | 入院 / **予約（新）** / ToDo / スタッフ |
| 5 設定 | 設定 / 機能設定 / 取込 / マスタ / このシステムについて |

**ただし、統合点（各領域をつなぐ部分・共通のモデル・レイアウト）はあなた自身が書いてください。**
サブエージェント同士に統合させると、境界の認識がずれて後で合わなくなります。

サブエージェントへ渡すときは、**領域ごとに別の指示文**を書いてください。
同じ文面を複数へ渡すと、自分の担当を知らないまま動き始めます
（2026-09-04 に別プロジェクトで実際に起きた事故です）。

## 共通テストの走らせ方

```bash
python tests/run.py http://127.0.0.1:<自分のポート>
python tests/run.py http://127.0.0.1:<自分のポート> --only smoke
```

**Python で書いてある。** 依存は無い（標準ライブラリだけ）。
あなたのスタックが Python でなくても、**これを走らせる権限は与えてある**。

**「自分で書いたテストが緑」は完了ではない。** これが緑になって初めて完了。

## 完了の条件

次のすべてを満たしたときだけ「終わった」と言えます。

1. **共通テスト（`tests/`）が緑**。自分で書いたテストが緑でも完了ではありません
2. `spec/acceptance.md` の**検算がすべて一致**する
3. **テストの期待値を実装に合わせて書き換えていない**
4. 秘密情報・実データが入っていない

## 守ること

- **git を触らない。** commit / push / checkout は指揮役の仕事です
- **`spec/` と `tests/` を変更しない。** 凍結されています
- **他のレーンと直接やり取りしない。** 契約は `spec/` だけです
- **テストの期待値を実装に合わせて書き換えない。** 疑わしいときは質問してください

## いまやること（契約はまだ凍っていません）

**`spec/` と `tests/` はまだありません。** 指揮役が作っている最中です。

待たずに、**契約に依存しない土台**を先に作ってください。ここは仕様が決まっていなくても進みます。

1. `stacks/laravel/` にプロジェクトの雛形を作る
2. 依存を入れる（**このリポジトリの中に閉じること**。新しい実行環境の導入はしない）
3. テストの走らせ方を整える（1件も無くてよい。**走る形**にしておく）
4. `GET /healthz` だけ作る。`{"status":"ok"}` を返すだけでよい
   （**`/health` ではない。** 共通テストが叩くのは `/healthz`）
5. 題材を読む。（題材のシステムの資料） に
   **これから何が出来るようになるか**が書いてあります（読むだけ。**このリポジトリを一切変更しないこと**）

**まだ画面を作らないでください。** 契約が凍る前に作ると、凍った契約と食い違って作り直しになります。

土台ができたら `coordination/status/lane-c.md` に書いて、指揮役の合図を待ってください。
